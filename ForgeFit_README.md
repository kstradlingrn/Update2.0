# ForgeFit — Illustrated and Spoken Coach Update

This ZIP contains the actual updated application, not just a list of requests.

## Install the update
1. Unzip the archive.
2. Replace `ForgeFit.html` in your existing GitHub repository with the included `ForgeFit.html`. Keep the same filename and folder.
3. Wait for GitHub Pages to finish publishing the commit.
4. Open https://kstradlingrn.github.io/Finsishedapp/ForgeFit.html in Safari and refresh.
5. To install the home-screen icon: Share → Add to Home Screen → Add.

The archive does not automatically update the live GitHub site. Keeping the same URL and browser preserves the app's existing local workout storage.

## Use the new features
- Build or open a workout, then choose **Single View** or **Full Plan**.
- Each exercise displays bundled start/action illustrations and written technique cues. Combination moves show each component separately.
- Choose **Woman**, **Man**, or **Drill Sergeant**, then tap **Talk me through it**. Use **Stop** to end guidance.
- Enable the next-exercise speech checkbox for automatic guidance when tapping Back or Next in Single View.
- Voice settings lets you select a voice for each coach. Available voices depend on your iPhone/browser; the drill sergeant uses firmer wording. Device voice availability may require manually choosing the preferred voice.
- **Alternative** offers same-muscle replacements first and other-muscle replacements below, filtered to available equipment, allowed positions, and exercise exclusions.
- **Alternative workout** builds a different plan; **Undo** restores the previous plan. A mixed plan can retain its cardio activity if needed.
- Existing real-photo and video links remain below the built-in illustrations.

The illustrations are embedded SVG drawings. No separate assets or image downloads are required. Online photo/video searches require an internet connection.
